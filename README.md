# nRF54LM20A 极客版 硬件超级自检与全能演示工程 (Cyber Geek Demo)

本工程是为自制 **Nordic nRF54LM20A** 开发板（模组型号：`ME54BS13-nRF54LM20A`）量身定制的**极客风全能硬件自检与动态交互演示工程**。

相比普通的静态自检 Demo，本工程全面引入了 **ANSI 终端彩色 UI 渲染**、**全套 24-bit HSV 平滑光效引擎**、**多模式 LED 流水/二进制时钟动画**、**手势按键识别（单击 / 长按）**、**W25Q128 速度基准跑分（Benchmark）** 以及 **串口键盘双向交互控制**！

---

## 1. 硬件引脚映射与原理图对照

对照原理图（`SCH_Schematic1_2026-10-29.pdf` / `nRF54LM20开发板 V1.0`）：

| 硬件外设 | 芯片引脚 | 网络标号 | 电气特性 / 硬件电路说明 |
| :--- | :--- | :--- | :--- |
| **调试串口 TX** | **P0.06** | `UART0_TXD` | 经过排针 H1 跳线接板载 CH343G 的 RXD（115200 8N1） |
| **调试串口 RX** | **P0.07** | `UART0_RXD` | 经过排针 H1 跳线接板载 CH343G 的 TXD（支持键盘字符交互） |
| **LED0 (LED1)** | **P1.22** | `LED0` | SI2302 N-MOS 低边驱动，GPIO 高电平点亮 |
| **LED1 (LED2)** | **P1.25** | `LED1` | SI2302 N-MOS 低边驱动，GPIO 高电平点亮 |
| **LED2 (LED3)** | **P1.27** | `LED2` | SI2302 N-MOS 低边驱动，GPIO 高电平点亮 |
| **LED3 (LED4)** | **P1.28** | `LED3` | SI2302 N-MOS 低边驱动，GPIO 高电平点亮 |
| **按键 SW1 (BTN0)** | **P1.26** | `BUTTON0` | 轻触按键对地导通，内部弱上拉，支持单击与长按识别 |
| **按键 SW2 (BTN1)** | **P1.09** | `BUTTON1` | 轻触按键对地导通，内部弱上拉，支持单击与长按识别 |
| **按键 SW3 (BTN2)** | **P1.08** | `BUTTON2` | 轻触按键对地导通，内部弱上拉，支持单击与长按识别 |
| **按键 SW4 (BTN3)** | **P0.05** | `BUTTON3` | 轻触按键对地导通，内部弱上拉，支持单击与长按识别 |
| **全彩 RGB 灯 (LED5)** | **P1.11** | `WS2812B` | 经 R18 (220Ω) 串联电阻驱动 DIN，+5V 供电，128MHz 精确时序 |
| **Flash 片选 CS#** | **P2.05** | `QSPI_CS` | 板载 R19 10kΩ 上拉电阻至 3V3 |
| **Flash 时钟 CLK** | **P2.01** | `QSPI_SCK` | SPI00 时钟总线 (8 MHz) |
| **Flash 数据输入 DI** | **P2.02** | `QSPI_IO0` | SPI00 MOSI |
| **Flash 数据输出 DO** | **P2.04** | `QSPI_IO1` | SPI00 MISO |
| **Flash 写保护 WP#** | **P2.03** | `QSPI_IO2` | 软件在 `PRE_KERNEL_1` 阶段自动拉高（解除写保护） |
| **Flash 暂停 HOLD#** | **P2.00** | `QSPI_IO3` | 软件在 `PRE_KERNEL_1` 阶段自动拉高（解除暂停状态） |

> [!IMPORTANT]
> **排针 H1 跳线设置**：请确保排针 H1 上的跳线帽已插好：
> - **Pin 1 - Pin 2** 短接（CH343G `RXD` ↔ `UART0_TXD`）
> - **Pin 3 - Pin 4** 短接（CH343G `TXD` ↔ `UART0_RXD`）

## 2. 炫酷亮点特性详解

### 🌟 亮点 1：ANSI TrueColor 终端实时色彩渲染
在 VS Code 串口监视器、Windows Terminal、MobaXterm 或 PuTTY 等支持 ANSI 的现代终端中打开串口，**终端会直接用 24 位真彩色色块实时显示当前 WS2812B 灯珠的真实发光色彩**，所见即所得！
```text
[00:12] LEDs:[● ○ ○ ●] | BTNs:[0 0 0 0] | RGB: █ #00FF88 (RAINBOW) | Flash: PASS ✔
```

### 🌟 亮点 2：WS2812B 梦幻动态光效引擎
- **模式 0【彩虹流光】**：全彩 256 阶色相平滑无缝轮转。
- **模式 1【霓虹呼吸】**：人眼视觉二次方 Gamma 缓动曲线平滑呼吸。
- **模式 2【能量脉冲】**：赛博朋克极速双色能量爆闪。
- **模式 3【按键交互】**：单击按键唤醒对应专属高饱和度色彩（烈焰红、极光绿、赛博蓝、琥珀金）。
- **4 档全局亮度调节**：支持 10%、25%、50%、100% 亮度循环切换。

### 🌟 亮点 3：4 颗 LED 多样化动画引擎
- **模式 A【手动翻转】**：SW1~SW4 独立按键翻转亮灭。
- **模式 B【霹雳游侠】**：Knight Rider 往返流光扫描（`0 -> 1 -> 2 -> 3 -> 2 -> 1 -> 0`）。
- **模式 C【二进制时钟】**：将 4 颗 LED 作为 4 位二进制计数器，实时累加（`0000` 到 `1111`）。
- **模式 D【急速跑马】**：快节奏顺时针环形流光跑马灯。

### 🌟 亮点 4：智能按键手势系统
- **单击操作**：切换对应 LED 状态并显示专属颜色。
- **长按操作 (> 800 ms)**：
  - **长按 SW1**：重新触发 Flash 性能跑分！
  - **长按 SW2**：循环切换 4 颗 LED 动画模式！
  - **长按 SW3**：平滑调节 WS2812B 整体亮度等级！
  - **长按 SW4**：循环切换 WS2812B 动态光效！

### 🌟 亮点 5：双向串口键盘交互（无需操作开发板即可远程控制）
在电脑键盘上直接敲击按键：
- 敲击 `1`：随时重新运行 Flash 吞吐量基准跑分。
- 敲击 `2`：切换 WS2812B 动态光效。
- 敲击 `3`：切换 4 颗 LED 动画模式。
- 敲击 `b`：调节灯光亮度等级。
- 敲击 `h`：打印交互控制菜单。

### 🌟 亮点 6：W25Q128JVSIQ 深度性能跑分（Benchmark）
- **4 KiB 扇区擦除速度跑分**：测试物理擦除耗时并计算擦除吞吐量（KB/s）。
- **空白擦除状态校验**：逐字节校验 0xFF。
- **256 字节完整 Page Program 页写入测试**：统计写速度与吞吐量（KB/s）。
- **1024 字节突发读取速度跑分**：统计读取吞吐量（KB/s）。
- **ANSI 彩色高亮内存拓扑 Dump**：黄/青/绿三色高亮地址、十六进制数据与 ASCII 码对照表。

## 3. 编译与烧录指南（在编译电脑上操作）

### 编译命令
在工程根目录下执行：
```bash
west build -b nrf54lm20dk/nrf54lm20a/cpuapp -p auto
```
*(Windows 下直接双击 `build.bat`，Linux/macOS 下执行 `./build.sh` 即可)*

### 烧录固件
连接 SWD 接口后执行：
```bash
west flash
```
或使用 `nrfjprog`：
```bash
nrfjprog --program build/zephyr/zephyr.hex --chiperase --reset
```
